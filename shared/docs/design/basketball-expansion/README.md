## 文件内容

- `01_L1_新角色_标准格式.tsv`：新增 **85** 个角色必杀，严格按照《文字技能设计指南》的 L1 字段，可用于 Arena/足球/篮球共享数据库。

- `02_L2_篮球双字连携_标准格式.tsv`：新增 **171** 个 2 字搭档技能，均严格使用已有 trigger/primitive/risk。

**新增候选合计：286 项**，不是已经部署到游戏内的条目。

### 跟已实现数据的关系

上传的《文化技能实施报告》确认已有篮球 2v2 **91 组搭档 + 16 组对阵**。本包与报告中的 91 组搭档、16 组对阵、126 个列出角色条目做了 exact-key 去重。

注意：这只是**按上传报告进行字词键的去重**，并非对真实仓库当前源码逐条查重；Claude 接入时仍须扫描 `shared/src/`，处理别名、Unicode NFC、技能语义重复及后续新增项。

### 核心可玩性原则

1. **一个字一个角色，两个字一对搭档。** 一键组队时按字素簇拆成两个球员；自由组队时输入框里一个完整词语仍是一名球员。
2. **L1 / L2 / L3 彼此分离。** L1 的「绝杀」是一个完整角色，但 L2 的「绝杀」则会被拆成「绝」和「杀」两名球员。
3. **真实篮球，不能直接加分。** 真球必须可传、被断、打板、弹框、盖帽，只有真实球体满足入筐判定才记 2/3 分。
4. **搞笑失败也是玩法。** `wild`、`miscomm`、`crash` 等要影响模拟，不能仅字幕演出。
5. **素材安全。** 传统神话民俗题材可以创作原创特效；现代影视/体育 IP 名字不能自动附带受版权保护的肖像、音乐和台词。
6. **模拟确定性**：随机仅使用比赛种子，回放/分享/战报不受破坏。
