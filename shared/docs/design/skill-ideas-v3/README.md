# Glyph Rumble · 文字、词组与体育队伍新技能 V3

基于上传的 `Glyph Soccer 4v4 — 字形足球` 开发说明进行扩展。**全部是新创意候选，并非已经实现。**

## 与现有项目保持一致

- Soccer = **4v4**，四字一键组队拆成四名球员；自由组队中的完整词语仍是一名球员。
- Basketball = **2v2**，两字一键组队拆成两名球员；自由组队可以每格输入一个完整词语或颜文字。
- 单字、完整词语是**球员层技能**；四字成语和两字搭档是**球队层技能**，球队名不是额外球员。
- 原有足球 12 个成语（龙飞凤舞、风平浪静、火上浇油、画蛇添足、一鸣惊人、虎头蛇尾、四面楚歌、天马行空、鸡飞狗跳、乱七八糟、无法无天、大吉大利）不重复覆盖。
- 原有 Soccer 的技能映射在 `shared/src/sports/skills.ts`，球队组合在 `shared/src/sports/combos.ts`，角色属性和特效共用；请先查代码，不要仅按 README 推断代码结构。
- 足球沿用现有 fixed timestep / seeded RNG / 真实球体物理 / 动态守门员 / 非脚本进球；原足球说明中球员招式冷却为 13–18 秒、每场最多使用 3 次，不擅自打破。
- 足球额外连携按现有球队连携的冷却和触发体系集成，不允许直接宣告进球、强行改变比分或生成第二颗真实足球。
- 篮球新设计为**候选需求**；上传文档只证明足球实现，尚不能据此断言篮球相关功能已经完成。
- 所有技能必须明确能看见的原因与代价：动作有前摇、可被反制、持续短，不强制命中。**S**=第一批；**A**=第二批；**B**=有趣但可后做。

## 建议首批验证的组合

- 单字：`伞 / 镜 / 锅 / 纸 / 胶 / 歪 / 停 / 影`。
- 完整词语角色：`开会 / 放假 / 工资 / 堵车 / 电梯 / 迷路 / 重启 / 截图 / 排队 / 打喷嚏`。
- 足球：`声东击西 / 守株待兔 / 亡羊补牢 / 金蝉脱壳 / 一石二鸟 / 兵不厌诈 / 同心协力 / 手忙脚乱`。
- 篮球：`高低 / 轻重 / 远近 / 进退 / 快慢 / 动静 / 天地 / 龟兔 / 铁壁 / 弹簧`。

## 与 Claude Code 的集成要求

1. 读现有源码，建立词条查重报告，尊重原有 ID、别名、Unicode 字素簇与长词优先匹配规则。
2. 将球员技能与球队连携拆开：一键组队 `高低` 是两名队员 `高`+`低` 的搭档；自由组队中角色 `高低` 如被允许作为完整词语，则只触发其角色词条而非自动拆队。
3. 用既有招式类型做实现基础（传球、挡拆、变向、减速、虚影、反弹、弹跳等），仅为明显不同的动作添加极少量新特效。
4. 所有高优先级技能至少有：可观察前摇、触发窗口、碰撞/控球实际效果、结束和冷却、对手可防御或躲开的途径。
5. 对球、比分和历史分享结果的影响必须由模拟产生，不能靠演出或战报硬编码结果。
6. 战斗中避免制造大量新的 Mesh、材质或 Shader。固定随机种子下重复可复现。
7. 新增自动测试：匹配优先级、模式人数、球员技能与球队连携分离、物理边界、技能频率、比分一致性、分享参数回放；生产构建验证。
8. 更新文档生成器，候选项必须标记未实现，不得误写进已上线技能清单。
