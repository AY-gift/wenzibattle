# Glyph Rumble 3D｜完整文化技能创意与开发任务包

**这是全量一次性交付，不是分期计划。**

总计 **466** 条候选：四字足球队 **231** 条、双字篮球搭档 **91** 条、单字/完整词语角色技能 **106** 条、特殊文化对阵事件 **38** 条。

这些是**候选记录数量**，不是保证全部为净新增的数量。Claude Code 必须按现有仓库逐条去重：已实现的标记 `existing` 并保留；未实现的逐条实现并测试；真正受阻的标记 `blocked`，不能假装完成。

## 使用方法

1. 将整个 ZIP 上传到同一个 Claude Code Cloud 会话的项目中，或解压后把目录加入 Git 仓库。
2. 请 Claude **首先阅读 `00_交给ClaudeCode_完整开发指令.md`，再读取所有四个 TSV 文件**，不要只读总览。
3. 发送：「请按任务包一次性完成整个项目，禁止只做首批，不要停下来等我批准下一批；直接持续开发并自动测试，最后统一交付。」

## 文件说明

- `00_交给ClaudeCode_完整开发指令.md`：完整交付目标、角色和模式兼容、实现方法、测试验收。
- `01_足球四字文化连携.tsv`：四字球队及对阵技能原型，含中文影视、历史典故、现代互联网、日本文化和英语四字符输入。
- `02_篮球双字文化搭档.tsv`：两字搭档及二人篮球配合。
- `03_单字与完整词语角色.tsv`：完整角色技能及竞技场、足球、篮球适配。
- `04_特殊对阵与文化彩蛋.tsv`：两队同时匹配时的解说和战术互动。
- `Glyph_Rumble_文化技能_单文件全量版.md`：上述内容整合为单个 Markdown 文档，若上传 ZIP 不方便，**只上传这一份文件也可以**。

此任务直接复用用户现有 Glyph Soccer README 所描述的 4v4、现有 12 项成语连携、自动比赛、种子确定性、分享与性能约束；不会替换原有作品素材。
