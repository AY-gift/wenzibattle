# Glyph Rumble 3D · 日常文字与词语特殊技能新增候选

> 状态：**设计候选 / 未实现**。这份文件用于给 Claude Code 导入或参考，**不是现有已上线技能清单**。请先检查仓库的真实技能数据表，逐项去重和决定实现优先级。

## 规则

- 单字、短词、完整颜文字分别匹配；**完整短语优先，最长匹配优先**。
- 同输入的普通攻击与必杀技应具有**可见的动作区别**，不要只换字幕和粒子颜色。
- **S = 第一批优先**，A = 第二批，B = 备选。建议先在四组中总共做 15–25 个 S 项目，而不是一次实现全部。
- 先复用现有动作（冲刺、击退、反弹、滑地、倒地、牵引、短眩晕、投射物、跳砸、分身、范围声波、方向扰乱等）；特别动作可创建少量共享道具 Mesh。
- 不得永久控制、无限伤害或保证获胜。一个角色同时触发多个词时，每次只选一个主必杀技，触发概率与冷却按原战斗平衡系统决定。
- 若匹配不到词语，保留现有的字体/字形生成、行为和必杀技回退规则。
- 颜文字请按完整 grapheme 序列和原字符串归一化处理，保留必要空格；Emoji ZWJ 组合不可拆解。
- 特别提醒：既有「尼玛」≠ 单独的「妈」，此处增加的是**妈／妈妈／爸／爸爸**等独立词条；不要覆盖原梗词数据。
