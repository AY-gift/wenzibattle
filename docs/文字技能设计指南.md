# Glyph Rumble 文字技能设计指南（给设计者 / AI 助手）

> 用途：把这份文档交给 GPT 或策划，让它按同一套规则设计新的「文字技能」，产出能直接被程序接入的表格。
> 游戏：Glyph Rumble（字形乱斗）。玩家输入文字，每个字/词变成一个 3D 字形角色。共有三个游戏：
> **擂台 1v1**、**足球 4v4**、**篮球 2v2**。三个游戏共用同一套角色和技能数据。

---

## 1. 三层结构（先搞清楚自己在设计哪一层）

| 层 | 是什么 | 例子 | 生效范围 |
| --- | --- | --- | --- |
| **L1 角色必杀** | 一个字、一个词、一个 emoji、一个颜文字就是一个角色，有一个必杀技 | 「伞」反向撑伞、「妈妈」吃饭啦！、「404」 | 擂台直接用；足球、篮球自动翻译成对应的球场技能 |
| **L2 队伍连携** | 足球四个字组成的队名、篮球两个字组成的搭档名，整组完全匹配才触发 | 足球「少林足球」、篮球「冰火」 | 只在对应运动里生效 |
| **L3 特殊对阵** | 两支已登记的队伍相遇时的彩蛋 | 「少林足球」对「足球小将」 | 开场播报 + 一条对决规则 |

**组队规则（不能改）：**
- **一键组队**按 Unicode 字素簇拆字：足球必须正好 4 个，篮球必须正好 2 个。
- **自由组队**每格是一个完整角色：「妈妈」是一个人，不会拆成两个「妈」。
- 队名不是额外的球员。
- 没登记的任何文字也能正常比赛，只是没有连携。

---

## 2. 设计铁律

1. **不能直接给分。** 任何技能都不能写比分、宣布进球、生成第二个球。射门/投篮必须是真的球在飞，可以被扑、被盖、打铁。
2. **有代价、有前摇、可反制。** 每个技能都有触发条件、冷却和每场次数上限。效果是短时的（通常 1–8 秒），不能永久控制对手。
3. **允许搞笑失败。** 失败通过「风险」字段在模拟里真的发生（摔倒、互撞、踢飞、乌龙方向），而不是播一段固定动画。
4. **确定性。** 所有随机由比赛种子决定（同一阵容 + 种子 = 同一场比赛），设计时不要依赖「真随机」。
5. **只用现有机制组合。** 新技能尽量用下面列出的机制 + 道具 + 名字来表达。确实需要新机制时，单独写一行「新机制需求」说明。
6. **内容安全：**
   - 不用政治敏感词。
   - 不做针对真实个人的辱骂；网络梗只做表演，不攻击真人。
   - 影视/动漫名只当触发关键词，效果和台词必须原创，不复述受版权保护的台词或情节。
7. **不覆盖已有内容。** 已存在的角色/连携只做补充说明。设计前先说明「复用已有」还是「新增」。

## 3. L1：角色必杀（擂台）

每个角色 = 一种**机制（kind）** + 可选**参数（opts）** + 三语名字。

| kind | 擂台效果 | 适合的字/词 |
| --- | --- | --- |
| `barrage` | 连续出拳 | 手、拳、打、猫 |
| `uppercut` | 升龙拳，把对手打上天 | 龙、上、锅、勺、电梯 |
| `quake` | 跺地冲击波 | 地、爆、坐 |
| `beam` | 光线 / 远距离直线攻击 | 眼、光、笔、弓、针 |
| `whirlwind` | 旋风回转 | 风、轮、沙 |
| `charge` | 直线冲撞 | 牛、车、纸飞机、地铁 |
| `fireCharge` | 带火冲撞 | 火、辣 |
| `giant` | 变巨大 | 王、塔 |
| `freeze` | 冻住对手 | 冰、锁、网、筷 |
| `heal` | 回血 | 药、茶、重启 |
| `meteor` | 天降流星 / 火雨 | 星、雨 |
| `kick` | 飞踢 | 脚、桥、少林 |
| `throw` | 过肩摔 | 投、武功 |
| `shield` | 防御 / 反弹 | 盾、伞、锚、排队 |
| `roar` | 吼叫击退（锥形） | 吼、钟、闹钟、打喷嚏 |

| `poison` | 毒气 / 云雾区域 | 毒、云、盐 |

| `sweep` | 扫腿 / 横扫 | 鞋、工资 |
| `giantFall` | 变大后砸下 | 得意忘形 |
| `swallow` | 吞下再吐出 | 吞 |
| `mountain` | 不动如山 | 山 |

| `glare` | 死亡凝视（定住） | ಠ_ಠ |

| `clones` | 分身 / 一群小东西 | 影、鸭、虫、动画 |

### 3.2 可选参数（opts）

| 参数 | 含义 |
| --- | --- |
| `prop` | 道具（emoji 或字），例如 `☂️`、`📦` |
| `props` | 多个道具轮流掉落 |
| `count` | 掉几个 |
| `arc` | 从角色身上抛出，而不是从天上掉 |
| `hold` | 整个技能期间手里拿着道具 |
| `propAt` | 道具出现在自己身上（`self`）或对手身上（`opponent`），纯表现 |
| `onHit` | 道具命中后附加状态：`freeze` / `confuse` / `sleep` |
| `selfFall` | 结尾自己摔倒（搞笑代价） |
| `selfSleep` | 结尾自己睡着 |
| `selfStun` | 结尾自己晕 |
| `counter` | 结尾弹起来反击 |
| `pulses` | 吼几次，越来越强 |
| `countdown` | 先数 1-2-3 |
| `darkness` | 全场变暗 |
| `grow` | 技能期间变大倍数 |
| `fx` | 视觉风味：`water` / `gas` / `paper` / `heart` / `ice` / `wind` |
| `dmgScale` / `kbScale` / `upScale` | 伤害、击退、击飞倍率 |
| `normal` | 平时打法标签：`hasty` 急躁、`sleepy` 爱睡、`ghost` 穿透、`heavy` 稳重、`tiny` 小只、`bouncy` 有弹性、`chaos` 难以预测、`slip` 易滑倒、`royal` 傲慢、`charm` 魅惑、`angry` 暴躁、`spinner` 旋转等 |

### 3.3 同一个角色在球场上会变成什么（自动映射，不用单独设计）

| 擂台机制 | 足球 | 篮球 |
| --- | --- | --- |
| kick / fireCharge | 强力射门 | 暴力扣篮（撞开防守） |
| whirlwind / fishSlap | 弧线射门 | 转身突破上篮 |
| beam | 光线射门（极快、平飞） | 激光三分（快、难盖） |
| uppercut / meteor | 天外飞仙吊射 | 天钩高抛（难盖） |
| barrage / charge / rage / random | 冲刺带球（撞人） | 突破冲刺（撞人） |
| feint / vanish | 瞬移甩开盯防 | 瞬移甩开防守 |
| clones | 分身迷惑附近对手 | 分身迷惑防守 |
| quake / roar / sweep / topple … | 冲击波推倒周围 | 冲击波（抢篮板、清场） |
| freeze / glare / lecture / joke / confuse / bribe | 让对手短暂定身 / 睡 / 笑 / 迷惑 | 同左，用来抢断 |
| throw / magnet / chomp / swallow | 远程抢球 | 远程抢断 |
| drop | 天降道具砸持球人 | 天降道具干扰持球人 |
| poison | 毒气减速区 | 毒气减速区 |
| shield / giant / mountain / lazy / blame | 铁壁（守门、反弹射门） | 篮下铁壁（盖帽范围变大） |
| heal | 全队提速、加快冷却 | 全队提速 |

> 所以**新角色只需要选 kind + opts + 名字**，三个游戏都能用。

### 3.4 L1 交付格式（TSV，一行一个角色）

```
文字	别名(繁体/日文,用/分隔)	kind	opts(JSON)	normal标签	日文名	中文名	英文名	设计说明
伞	傘	shield	{"prop":"☂️","hold":true}		逆さ傘ガード	反向撑伞	Inside-Out Umbrella	伞面反弹靠近的单位
```

## 4. L2：足球四字连携（4v4）

每个四字队名 = **触发条件 + 1–3 个原语（按顺序执行）+ 风险**。

### 4.1 触发条件

| 触发 | 说明 |
| --- | --- |
| `attack` | 本方在后场 / 中场组织进攻 |
| `midfield` | 中场持球 |
| `final3` | 球门前持球 |
| `flank` | 边路持球 |
| `pressed` | 持球人被包夹 |
| `defend` | 对手攻入本方半场 |
| `danger` | 对手在本方门前 |
| `loose` | 争夺无主球 |
| `lostBall` | 刚丢球权 |
| `kickoff` | 开球后 |
| `behind` | 落后时 |
| `lateBehind` | 最后阶段落后 |
| `lateAhead` | 最后阶段领先 |
| `late` | 最后阶段 |
| `afterConcede` | 刚丢球 |
| `afterShot` | 射门弹出后 |
| `afterSave` | 刚扑出射门 |
| `afterTackle` | 刚抢断 |
| `any` | 随时（概率低） |

### 4.2 原语

| 类 | 原语 | 效果 |
| --- | --- | --- |
| 持球动作 | `passChain` | 连续一脚传球，最后射门 |
| | `throughBall` | 直塞给最前面的队友并让他加速 |
| | `lobPass` | 高吊传球后凌空射门 |
| | `longShot` | 远距离强力射门 |
| | `curveShot` | 从门柱外绕进的弧线球 |
| | `skyShot` | 超高弧线吊门 |
| | `fakeShot` | 假射骗倒门将再横传 |
| | `boardPass` | 打围板反弹传给队友 |
| | `switchPlay` | 转移到另一侧 |
| | `dribbleBurst` | 不怕铲的强行突破 |
| 团队效果（几秒） | `sprint` | 全队提速 |
| | `allOut` | 全员压上（没人守门） |
| | `retreat` | 全员回防 |
| | `swapPositions` | 队友瞬间互换位置 |
| | `chaosRun` | 满场乱跑 |
| | `wallLine` | 在球与球门之间排人墙 |
| | `press` | 围抢持球者 |
| | `keeperBoost` | 门将变铁壁 |
| | `calm` | 不会被撞倒或定身 |
| | `grip` | 控球不易被抢 |
| | `tackleBoost` | 抢断更强 |
| | `accuracy` | 传射更准 |
| | `recover` | 倒地队友立刻起身 |
| | `heavyScreen` | 最重的队员卡住对手 |
| | `celebrateBait` | 全队先停一下，之后满血加速 |
| | `playDead` | 全队装死，附近对手发愣 |
| | `peace` | 双方都减少乱斗和铲抢 |
| 对手 / 场地 | `markWrong` | 对手盯错人 |
| | `spotlight` | 对手集中盯明星，其他人空出来 |
| | `slowZone` | 对手脚下减速区 |

| | `scrambleOpp` | 打乱对手站位 |
| | `obstacle` | 纸箱滑进场，球会被弹开 |
| 运气 | `lucky` | 一次幸运反弹（打门柱 / 被扑后改向球门，仍可被挡） |
| | `extraKick` | 弹出后补一脚 |

### 4.3 风险（约 40% 发生）

| 风险 | 效果 |
| --- | --- |
| `none` | 无 |
| `trip` | 队友摔倒 |
| `crash` | 两名队友互撞 |
| `wild` | 下一脚踢飞 |
| `ownRisk` | 下一脚可能踢向自家球门 |
| `tired` | 之后变慢 |
| `gap` | 后防空出来（没人守门） |
| `celebrate` | 提前庆祝原地发呆 |
| `boardCrash` | 冲过头撞围板 |

### 4.4 L2 足球交付格式

```
队名(4字)	连携名	类别	触发	原语(逗号分隔,1-3个)	风险	设计说明(笑点)
少林足球	功夫球阵	film	attack	passChain,lobPass	crash	四人连续弹踢与旋转挑传；角度失误时踢到队友
```

**类别可选：** `film` 电影、`anime` 动漫、`myth` 神话、`idiom` 成语、`history` 历史、`society` 社会日常、`tech` 科技、`internet` 网络、`japanese` 日语、`english` 英语。

## 6. L3：特殊对阵

两支**都已登记**的队伍相遇时触发，蓝 / 红顺序可以互换。效果从下面四种里选一种：

| effect | 规则 |
| --- | --- |
| `counter` | 互相反制：一方发动连携后，另一方冷却立刻缩短 |
| `chaos` | 混战：开场阶段连携冷却减半 |
| `weather` | 天气：场地两边各出现一块减速区（两队都受影响） |
| `spotlight` | 聚光灯：开场一段时间对手集中盯明星 |

交付格式：

```
模式(足球/篮球)	队A	队B	对阵名	规则说明	effect
足球	少林足球	足球小将	功夫对热血	功夫反弹传球与蓄力远射各触发一次专属解说	counter
```
