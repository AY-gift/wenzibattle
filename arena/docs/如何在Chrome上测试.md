# 如何在 Chrome 上测试《字形乱斗 3D》

## 为什么不能直接双击 index.html？

游戏用的是现代网页技术（ES 模块、按需加载的字体文件）。Chrome 出于安全原因，**不允许从 `file://` 路径加载这些文件**，直接双击 `index.html` 只会看到白屏。
所以需要一个本地小服务器把文件“发”给浏览器。这个服务器只在你自己电脑上运行，不会上传任何东西。

## 最简单的方法：双击 `start-game.bat`

1. 先安装 **Node.js**（只需一次）：打开 <https://nodejs.org/>，下载 **LTS** 版本，一路“下一步”安装。
2. 在最上层文件夹（`D:\GameDevelopmentRandom`）里双击 **`start-game.bat`**。
   - 第一次运行会自动安装依赖（需要联网，一两分钟）。
   - 然后会自动用 Chrome 打开 <http://localhost:5173>。
3. 测试完，关掉那个黑色的命令行窗口就停止了。

如果 Chrome 没有自动打开，就手动在 Chrome 地址栏输入 `http://localhost:5173`。

## 用命令行启动（和上面效果一样）

```bash
npm install
```

```bash
npm start
```

## 测试正式版（打包后的版本，更接近上线效果）

```bash
npm run build
```

```bash
npm run preview
```

然后在 Chrome 打开 <http://localhost:4173>。
`dist/` 文件夹可以直接上传到任意静态网站托管（GitHub Pages、Netlify、Vercel 等），上传后别人用网址就能玩，不需要再开服务。

## 用手机测试

电脑和手机连同一个 Wi-Fi，然后运行：

```bash
npx vite --host
```

命令行里会显示一个 `Network: http://192.168.x.x:5173` 的地址，用手机浏览器打开它即可。

## 有用的网址参数

| 网址 | 作用 |
| --- | --- |
| `http://localhost:5173/?fps` | 右上角显示帧率和当前画质，方便排查掉帧 |
| `http://localhost:5173/?lang=zh` | 直接用中文界面（`ja` 日语 / `en` 英语） |
| `http://localhost:5173/?a=尼玛&b=煞笔` | 直接填好两个选手 |
| `http://localhost:5173/?a=火&b=水&seed=123` | 用固定种子，重现同一场比赛 |
| `http://localhost:5173/selftest.html` | 自检页面：测试所有必测文字、统计胜率、测渲染性能 |

## 掉帧怎么办？

- 右上角点 **“画质：高”** 切换到 **“画质：低”**：关闭阴影、彩色聚光灯和光柱，降低分辨率和粒子数量。
- 游戏会自动检测：连续卡顿会先降到低画质，还卡就再降低渲染分辨率。
- 打开 `?fps` 看帧率。如果低画质下仍低于 30 FPS，可以把帧率数字和电脑型号告诉开发者。
- 打中时画面会有极短的“停顿”，放必杀技时会有慢动作。这些是故意做的打击感特效，不是卡顿。
- Chrome 里如果开着很多标签页或视频，也会抢显卡资源。
